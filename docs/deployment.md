Status: **not yet done.** This is the plan to version-control the site and deploy it. Pick it up when ready.

## Goal
Create a git repo → push to a **private GitHub repo** → connect **Vercel** for continuous deployment (auto-deploy on push to `main`, preview URLs on branches/PRs). No environment variables are needed yet (the code reads no `process.env`; RSVP is a stub, the hero image is a hardcoded URL).

Note: `AGENTS.md` is auto-generated by `next dev`; commit it as-is. Vercel runs `next build` (not `next dev`), so it won't be regenerated there.

## Step 2 — Push to a private GitHub repo
```bash
# 1) Re-authenticate gh (interactive — run yourself):
gh auth login            # GitHub.com → HTTPS → authenticate via browser

# 2) Create the private repo and push in one step:
gh repo create wedding-suren-ruby --private --source=. --remote=origin --push
```
Manual fallback: create the repo on github.com, then
`git remote add origin <url> && git push -u origin main`.

## Step 3 — Connect Vercel (dashboard)
1. vercel.com → sign up / log in with **"Continue with GitHub"**.
2. **Add New… → Project** → import `wedding-suren-ruby`. Grant Vercel access to the private repo (Vercel GitHub app → "Only select repositories" → this one).
3. Vercel auto-detects **Next.js** — leave Build Command (`next build`), Output, and Root Directory (`./`) at defaults. **No environment variables.**
4. **Deploy** → you get a production URL like `wedding-suren-ruby.vercel.app`.

Optional: Project Settings → General → Node.js Version → 22.x (default is fine for Next 16).

## Step 4 — Verify
